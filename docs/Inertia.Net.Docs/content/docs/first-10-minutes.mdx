Create the React starter (choose `vue` or `svelte` for another client; add `--tfm net11.0` to target .NET 11 instead of .NET 10):

```sh
dotnet new install Inertia.Net.Templates::1.8.0
dotnet new inertia -n MyApp --framework react
cd MyApp
npm install
npm run dev
```

Use `bun install` and `bun run dev`, `pnpm install` and `pnpm run dev`, or `yarn install` and `yarn run dev` if you prefer. In a second terminal run `dotnet run`. Open the address printed by `dotnet run` (`http://localhost:5180` for the template) and visit `/todos`; submit an empty title to see the validation message. The template includes Vite, antiforgery and a complete form.

<Callout type="warning" title="Open the .NET URL, not the Vite one">
Vite prints `http://localhost:5173` when it starts, but that server only supplies JavaScript, CSS and hot reload to your app. It has no pages, so opening it shows a blank page. Your app is the ASP.NET Core address from `dotnet run`: `http://localhost:5180`.
</Callout>

The handler in `Program.cs` is:

```csharp
app.MapPost("/todos", (HttpContext http, TodoStore todos, NewTodo input) =>
{
    todos.Add(input.Title!);
    http.Inertia().Flash("success", "Todo added");
    return Results.Redirect("/todos");
}).WithInertiaValidation();
```

`NewTodo.Title` has `[Required, StringLength(100)]`; invalid requests redirect with errors before the handler runs. The React template's `ClientApp/pages/Todos/Index.tsx` uses `useForm` to submit and display the error:

```tsx
import { useForm } from '@inertiajs/react'
import type { FormEvent } from 'react'

// Inside the page component:
const form = useForm({ title: '' })
const submit = (e: FormEvent) => {
  e.preventDefault()
  form.post('/todos', { onSuccess: () => form.reset() })
}

// Inside its return:
<form onSubmit={submit}>
  <input placeholder="What needs doing?" value={form.data.title} onChange={(e) => form.setData('title', e.target.value)} />
  <button type="submit" disabled={form.processing}>Add</button>
  {form.errors.title && <div style={{ color: 'crimson' }}>{form.errors.title}</div>}
</form>
```

To test the round trip, add `Inertia.Net.Testing` and `Microsoft.AspNetCore.Mvc.Testing` to a test project, expose `public partial class Program;` in the app, and create a cookie-preserving `WebApplicationFactory<Program>` client with `AllowAutoRedirect = false`:

```csharp
using System.Net;
using System.Net.Http.Json;
using Inertia.Net.Testing;

client.DefaultRequestHeaders.Accept.ParseAdd("text/html");
using var page = await client.GetAsync("/todos");
using var request = new HttpRequestMessage(HttpMethod.Post, "/todos")
{
    Content = JsonContent.Create(new { title = "" }),
};
request.Headers.Add("X-Inertia", "true");
request.Headers.Add("X-Requested-With", "XMLHttpRequest");
request.Headers.Referrer = new Uri(client.BaseAddress!, "/todos");
request.WithXsrfToken(page);
using var response = await client.SendAsync(request);
Assert.Equal(HttpStatusCode.Redirect, response.StatusCode);
using var redirected = await client.GetAsync("/todos");
await redirected.AssertInertiaAsync(p => p.HasErrors().HasError("title"));
```

See [Testing](/docs/testing) for named error bags and custom XSRF names, and [Quick start](/docs/quick-start) for an existing application.
