ForgetMeNot is a small todo app, but it uses the same pieces as a real product: sign-in, private data, a public share page, a list that loads as you scroll, and reminders that run in the background. You will start from the official `Inertia.Net.Templates` template, then add each feature one small step at a time.

<Callout type="info" title="What you need">
- .NET 10 SDK
- Bun 1.4 or newer
- A code editor
- A terminal

No database server is required. ForgetMeNot uses SQLite, and the template already gives you a working React app.
</Callout>

This guide is for someone who has not built an Inertia app before. Run the commands, look at the checkpoints, and only move on when the app behaves the way the checkpoint says.

## 1. Start from the template

Install the templates once, then create the app:

```sh
dotnet new install Inertia.Net.Templates::1.5.3
dotnet new inertia -n ForgetMeNot --framework react
cd ForgetMeNot
bun install
```

Start the two development processes. Keep both terminals open:

```sh
# terminal 1
bun run dev

# terminal 2
dotnet watch
```

Open `http://localhost:5180`. You should see the template home page and a working Todos page. Click around before changing anything.

<Callout type="tip" title="Checkpoint">
If the app does not load, run `dotnet new inertia --help` and confirm the template version. The frontend must be started before `dotnet watch` reads the Vite hot file, but a refresh is enough if you started them in the other order.
</Callout>

Open these files. You do not need to understand all of them yet:

```text
Program.cs
app.html
ClientApp/app.tsx
ClientApp/Layout.tsx
ClientApp/pages/Home.tsx
ClientApp/pages/Todos/Index.tsx
```

The template already has Inertia, Vite, a deferred prop, a form and validation. We are going to grow it into a full app.

## 2. Make it look good with shadcn/ui

## 3. Give the app a clean structure

The template keeps everything in `Program.cs`. We will move the setup into small files so `Program.cs` stays readable. Create these folders:

```text
ForgetMeNot/
  Data/
  Endpoints/
  Infrastructure/
```

The final `Program.cs` is only a few lines:

```csharp
using ForgetMeNot;
using ForgetMeNot.Endpoints;
using ForgetMeNot.Infrastructure;

var builder = WebApplication.CreateBuilder(args);
builder.AddForgetMeNot();

var app = builder.Build();
app.UseForgetMeNot();
app.MapForgetMeNot();

app.Run();
```

Each extension does one job:

| File | Responsibility |
|---|---|
| `Infrastructure/ForgetMeNotSetup.cs` | The one `AddForgetMeNot()` and `UseForgetMeNot()` entry point |
| `Infrastructure/DataSetup.cs` | EF Core and SQLite |
| `Infrastructure/SessionAuthSetup.cs` | Session, antiforgery and password hashing |
| `Infrastructure/InertiaSetup.cs` | Inertia options, shared props and SSR |
| `Infrastructure/SessionAuth.cs` | Sign in/out helpers and the `RequireSessionUser` filter |
| `Endpoints/AuthEndpoints.cs` | Register, login and logout |
| `Endpoints/TodoEndpoints.cs` | Private lists and items |
| `Endpoints/PublicEndpoints.cs` | The public share page |

A beginner can read `Program.cs` in one glance. That is the point.

The route table is also one readable file:

```csharp
// Endpoints/ForgetMeNotEndpoints.cs
```

## 5. Use sessions for sign-in

Sessions keep the signed-in user id and Inertia's flash/error state on the server. The browser only holds an HttpOnly session cookie.

```csharp
// Infrastructure/SessionAuthSetup.cs
public static class SessionAuthSetup
{
    public static WebApplicationBuilder AddForgetMeNotSessionAuth(this WebApplicationBuilder builder)
    {
        builder.Services.AddDistributedMemoryCache();
        builder.Services.AddSession(o =>
        {
            o.Cookie.Name = ".fmn.session";
            o.Cookie.HttpOnly = true;
            o.Cookie.IsEssential = true;
            o.Cookie.SameSite = SameSiteMode.Lax;
            o.Cookie.SecurePolicy = builder.Environment.IsDevelopment()
                ? CookieSecurePolicy.SameAsRequest
                : CookieSecurePolicy.Always;
            o.IdleTimeout = TimeSpan.FromDays(7);
        });

        builder.Services.AddAntiforgery(o => o.HeaderName = InertiaHeaders.XsrfToken);
        builder.Services.AddScoped<IPasswordHasher<AppUser>, PasswordHasher<AppUser>>();
        return builder;
    }

    public static WebApplication UseForgetMeNotSession(this WebApplication app)
    {
        app.UseSession();
        return app;
    }
}
```

The session helpers and the endpoint filter:

```csharp
// Infrastructure/SessionAuth.cs
public static class SessionAuth
{
    public const string UserIdKey = "fmn.user-id";
    public const string DisplayNameKey = "fmn.display-name";

    public static int? UserId(this HttpContext http) => http.Session.GetInt32(UserIdKey);

    public static void SignIn(this HttpContext http, AppUser user)
    {
        http.Session.SetInt32(UserIdKey, user.Id);
        http.Session.SetString(DisplayNameKey, user.DisplayName);
    }

    public static void SignOut(this HttpContext http) => http.Session.Clear();
}

public sealed class RequireSessionUser : IEndpointFilter
{
    public async ValueTask<object?> InvokeAsync(
        EndpointFilterInvocationContext context,
        EndpointFilterDelegate next)
    {
        if (context.HttpContext.UserId() is null)
        {
            return Inertia.Net.Inertia.Location("/login");
        }

        return await next(context);
    }
}
```

<Callout type="warning" title="One instance for this sample">
`AddDistributedMemoryCache()` keeps sessions in memory. That is fine for one app instance. For more than one replica, register a shared cache such as Redis, or the session will only exist on the instance that created it.
</Callout>

## 6. Hide the Inertia setup

`InertiaSetup.cs` is the only file a beginner needs to know when they want to change Inertia behavior.

```csharp
// Infrastructure/InertiaSetup.cs
public static class InertiaSetup
{
    public static WebApplicationBuilder AddForgetMeNotInertia(this WebApplicationBuilder builder)
    {
        builder.Services.AddInertia(o =>
        {
            o.Share("appName", "ForgetMeNot");
            o.Share("auth", ctx =>
            {
                var id = ctx.Session.GetInt32(SessionAuth.UserIdKey);
                var name = ctx.Session.GetString(SessionAuth.DisplayNameKey);
                return id is null ? null : new AuthUser(id.Value, name ?? "You");
            });
            o.Share("baseUrl", ctx =>
                $"{ctx.Request.Scheme}://{ctx.Request.Host}{ctx.Request.PathBase}");

            o.Pages.Directory = "ClientApp/pages";
            o.Vite.Prefetch = VitePrefetch.Waterfall;
            o.State.UseSession();                  // flash/errors live in the session too
            o.TypeScript.OutputPath = "ClientApp/types/inertia.d.ts";
            o.TypeScript.SharedProps<SharedProps>().FlashData<Flash>();
            o.Ssr.BundlePath = "ssr/ssr.js";
            o.Ssr.Mode = SsrMode.Preferred;
            o.Ssr.UseNodeProcess(n => n.Executable = "bun");
        });

        builder.Services.AddInertiaDevTools();
        return builder;
    }

    public static WebApplication UseForgetMeNotInertia(this WebApplication app)
    {
        app.UseInertia();
        app.UseInertiaAntiforgery();
        return app;
    }
}

public sealed record AuthUser(int Id, string DisplayName);
public sealed record SharedProps(string AppName, AuthUser? Auth, string BaseUrl);
public sealed record Flash(string? Success);
```

Now the aggregate setup:

```csharp
// Infrastructure/ForgetMeNotSetup.cs
public static class ForgetMeNotSetup
{
    public static WebApplicationBuilder AddForgetMeNot(this WebApplicationBuilder builder)
    {
        builder.Services.Configure<ForwardedHeadersOptions>(o =>
        {
            o.ForwardedHeaders = ForwardedHeaders.XForwardedFor | ForwardedHeaders.XForwardedProto;
            o.ForwardLimit = 1;
            o.KnownIPNetworks.Clear();
            o.KnownProxies.Clear();
        });

        builder.Services.AddValidation();
        builder.Services.AddProblemDetails();
        builder.Services.AddResponseCompression(o => o.EnableForHttps = true);
        builder.Services.ConfigureHttpJsonOptions(o =>
            o.SerializerOptions.TypeInfoResolverChain.Insert(0, AppJsonContext.Default));

        builder.AddForgetMeNotData();
        builder.AddForgetMeNotSessionAuth();
        builder.AddForgetMeNotInertia();
        return builder;
    }

    public static WebApplication UseForgetMeNot(this WebApplication app)
    {
        app.UseForwardedHeaders();
        app.UseResponseCompression();
        app.UseStaticFiles(new StaticFileOptions
        {
            OnPrepareResponse = c =>
            {
                if (c.Context.Request.Path.StartsWithSegments("/build/assets"))
                    c.Context.Response.Headers.CacheControl = "public, max-age=31536000, immutable";
            },
        });

        app.UseForgetMeNotSession();
        app.UseForgetMeNotInertia();
        app.EnsureForgetMeNotData();
        return app;
    }
}
```

`UseSession()` must run before `UseInertia()`. Add forwarded-header configuration if you deploy behind Coolify or another TLS proxy.

## 7. Register, sign in and sign out

The endpoints live in `Endpoints/AuthEndpoints.cs` and are mapped from `MapForgetMeNot()`. `WithInertiaValidation()` turns model errors into a redirect back with `errors`.

```csharp
public sealed class RegisterForm
{
    [Required, EmailAddress]
    public string? Email { get; set; }

    [Required, MinLength(8)]
    public string? Password { get; set; }

    [Required, MaxLength(80)]
    public string? DisplayName { get; set; }
}

public sealed class LoginForm
{
    [Required, EmailAddress]
    public string? Email { get; set; }

    [Required]
    public string? Password { get; set; }
}

public static class AuthEndpoints
{
    public static IEndpointRouteBuilder MapAuthEndpoints(this IEndpointRouteBuilder app)
    {
        app.MapPost("/register", async (
            RegisterForm form, AppDbContext db, IPasswordHasher<AppUser> hasher, HttpContext http) =>
        {
            var email = form.Email!.Trim().ToLowerInvariant();
            if (await db.Users.AnyAsync(u => u.Email == email))
            {
                return Back().WithErrors(new Dictionary<string, string>
                {
                    ["email"] = "An account with this email already exists.",
                });
            }

            var user = new AppUser
            {
                Email = email,
                DisplayName = form.DisplayName!.Trim(),
                PasswordHash = "",
            };
            user.PasswordHash = hasher.HashPassword(user, form.Password!);

            db.Users.Add(user);
            await db.SaveChangesAsync();

            http.Inertia().Flash("success", "Account created. Sign in to continue.");
            return Results.Redirect("/login");
        }).WithInertiaValidation();

        app.MapPost("/login", async (
            LoginForm form, AppDbContext db, IPasswordHasher<AppUser> hasher, HttpContext http) =>
        {
            var email = form.Email!.Trim().ToLowerInvariant();
            var user = await db.Users.SingleOrDefaultAsync(u => u.Email == email);

            if (user is null || hasher.VerifyHashedPassword(user, user.PasswordHash, form.Password!)
                == PasswordVerificationResult.Failed)
            {
                return Back().WithErrors(new Dictionary<string, string>
                {
                    ["email"] = "These credentials do not match our records.",
                });
            }

            http.SignIn(user);
            return Results.Redirect("/todos");
        }).WithInertiaValidation();

        app.MapPost("/logout", (HttpContext http) =>
        {
            http.SignOut();
            http.Inertia().ClearHistory();
            return Results.Redirect("/");
        });

        return app;
    }
}
```

## 8. Build the dashboard

Map the private endpoints from `TodoEndpoints.cs`:

```csharp
public static class TodoEndpoints
{
    public static IEndpointRouteBuilder MapTodoEndpoints(this IEndpointRouteBuilder app)
    {
        app.MapGet("/todos", async (HttpContext http, AppDbContext db, CancellationToken ct) =>
        {
            var userId = http.UserId()!.Value;

            var lists = await db.Lists
                .AsNoTracking()
                .Where(l => l.UserId == userId)
                .OrderBy(l => l.Title)
                .Select(l => new TodoListDto(
                    l.Id, l.Title, l.PublicSlug, l.IsPublic,
                    l.Items.Count, l.Items.Count(i => !i.IsDone)))
                .ToListAsync(ct);

            return Render("Todos/Index", new InertiaProps
            {
                ["lists"] = lists,
```

## 11. Send reminders once

A background service checks for due items every minute, sends them, and records `RemindedAt`.

```csharp
public interface IEmailSender
{
    Task SendAsync(string to, string subject, string body, CancellationToken ct = default);
}

public sealed class ReminderWorker(
    IServiceScopeFactory scopes,
    ILogger<ReminderWorker> logger) : BackgroundService
{
    protected override async Task ExecuteAsync(CancellationToken stoppingToken)
    {
        using var timer = new PeriodicTimer(TimeSpan.FromMinutes(1));

        while (await timer.WaitForNextTickAsync(stoppingToken))
        {
            using var scope = scopes.CreateScope();
            var db = scope.ServiceProvider.GetRequiredService<AppDbContext>();
            var mail = scope.ServiceProvider.GetRequiredService<IEmailSender>();
            var now = DateTimeOffset.UtcNow;

            var due = await db.Items
                .Include(i => i.List).ThenInclude(l => l.User)
                .Where(i => i.RemindAt != null && i.RemindAt <= now && i.RemindedAt == null)
                .OrderBy(i => i.RemindAt)
                .Take(100)
                .ToListAsync(stoppingToken);

            foreach (var item in due)
            {
                await mail.SendAsync(item.List.User.Email, $"Reminder: {item.Title}", item.Title, stoppingToken);
                item.RemindedAt = now;
            }

            if (due.Count > 0)
            {
                await db.SaveChangesAsync(stoppingToken);
                logger.LogInformation("Sent {Count} reminders", due.Count);
            }
        }
    }
}
```

Register the service in `ForgetMeNotSetup`:

```csharp
builder.Services.AddScoped<IEmailSender, SmtpEmailSender>(); // your implementation
builder.Services.AddHostedService<ReminderWorker>();
```

For a single instance, the timer is enough. For several instances, use a durable queue with leases (TickerQ, Hangfire or a database outbox) so only one worker claims each reminder.
