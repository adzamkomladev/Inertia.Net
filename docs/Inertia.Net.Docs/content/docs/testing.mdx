`Inertia.Net.Testing` has Laravel-style fluent assertions over Inertia responses and `HttpClient` helpers. It parses both JSON responses (`X-Inertia: true`) and the first-visit HTML `<script data-page>`. It also decodes `$bigint` values. A failed assertion throws `InertiaAssertionException` with a readable message, so the package works with any test framework.

## Check page files and large integers

By default, `Component("Users/Index")` checks only the returned component name. To also check that the page file exists, use this fragment inside a test:

```csharp
var options = new InertiaTestingOptions { EnsurePagesExist = true };
options.PageDirectories.Add("ClientApp/pages"); // Use an absolute path if the test runs elsewhere.
var page = await response.GetInertiaPageAsync();
new AssertableInertia(page, options).Component("Users/Index");
```

React, Vue and Svelte extensions are allowed by default. Change `PageExtensions` to narrow that list.
`Component("Users/Index", false)` skips the file check. Passing `true` forces it.

When the page enables `preserveBigIntegers`, `Where` and `HasFlash` compare `$bigint` markers as integers,
including nested values. The raw page stays unchanged. Without that flag, markers remain ordinary objects.

A complete test class looks like this:

```csharp
using Inertia.Net.Testing;
using Microsoft.AspNetCore.Mvc.Testing;

public class UsersTests(WebApplicationFactory<Program> factory) : IClassFixture<WebApplicationFactory<Program>>
{
    // Keeps cookies (flash, errors) and does not follow redirects, so a test can assert the 303 itself.
    private readonly HttpClient _client = factory.CreateClient(new WebApplicationFactoryClientOptions
    {
        AllowAutoRedirect = false,
    });

    [Fact]
    public async Task Index_lists_users()
    {
        using var response = await _client.InertiaGetAsync("/users");   // sends X-Inertia, X-Requested-With

        await response.AssertInertiaAsync(page => page
            .Component("Users/Index")
            .Url("/users")
            .Has("users", 3, first => first.Where("name", "Ann").WhereType("id", "integer").Etc())
            .Where("filters.search", "")
            .Missing("secret")
            .HasFlash("toast", "Welcome"));
    }
}
```

Add `public partial class Program;` to your app when it uses top-level statements.

To check that an error page keeps its HTTP status, use `Status` with the response's page assertion:

```csharp
using var response = await _client.InertiaGetAsync("/missing");
await response.AssertInertiaAsync(page => page.Status(404).Component("Error"));
```

## Test host recipe

With `WebApplicationFactory<Program>`, pin the asset version so that requests need no first visit to learn it. Also turn SSR (server-side rendering) off so that tests need no Node server:

```csharp
builder.ConfigureTestServices(services => services.PostConfigure<InertiaOptions>(o =>
{
    o.Version = "test";              // then client.InertiaGetAsync(url, version: "test")
    o.Ssr.Mode = SsrMode.Disabled;
}));
```

For form posts, read the XSRF token from a page response with `GetXsrfToken()` and send it with `WithXsrfToken()`. See [Testing a form with antiforgery](#testing-a-form-with-antiforgery). A client that keeps cookies holds the antiforgery cookie and the sign-in cookie between requests. Create one with `factory.CreateClient(new() { AllowAutoRedirect = false, HandleCookies = true })`.

## Request helpers

| Helper | Purpose |
|---|---|
| `InertiaGetAsync(url, version?, configure?)` | Sends an Inertia GET |
| `InertiaRequestAsync(method, url, content?, version?, configure?)` | Sends an Inertia request with any method |
| `GetInertiaPageAsync()` | Parses the response into an `InertiaPage` |
| `AssertInertiaAsync(assert)` | Parses, runs the assertions and returns the page |

## Page assertions

The page assertions are:

- `Component`, `Url` and `Version`.
- `HasFlash(key)`, `HasFlash(key, value)` and `MissingFlash(key)`.
- `HasDeferred(path)` and `HasDeferred(group, path)`.
- `HasLive(path)` and `HasLive(path, channel, event)` for [live props](/docs/live-props). Write the channel as `"{type}:{name}"`, for example `private:orders.1`.
- `HasHead(key)` or `HasHead(key, contains)` for [head tags](/docs/head-tags). The key matches the tags' `data-inertia` attribute: `title`, a meta name or property, or a link rel.

For example:

```csharp
await response.AssertInertiaAsync(page => page.HasHead("title", "Users - App").HasHead("description"));
```

## Prop assertions

These assertions work on props and nested scopes. Keys can use dot paths and array indexes:

`Has(key)`, `Has(key, count)`, `Has(key, scope)`, `Has(key, count, firstItemScope)`, `HasAll`, `HasAny`, `Missing`, `MissingAll`, `Where(key, value)`, `Where(key, predicate)`, `WhereNot`, `WhereNull`, `WhereNotNull`, `WhereType(key, "string|null")`, `WhereAllType`, `WhereContains(key, ...)`, `Count`, `CountBetween`, `Each(scope)`, `First(scope)` and `Dump()`.

`WhereRoute(key, url, method)` asserts a route sent as a prop in the client's `{ url, method }` shape. The generated [`routes.ts`](/docs/typed-routes) functions return that shape. The method defaults to `get`, and the comparison ignores case:

```csharp
await response.AssertInertiaAsync(page => page.WhereRoute("actions.delete", "/users/1", "delete"));
```

**Strict interaction tracking.** Like Laravel, a nested scope fails when it contains properties you did not assert, unless you end the scope with `Etc()`. The root scope is not checked automatically. Call `.Interacted()` at the end to require that every top-level prop was asserted.

## Partial reloads and deferred props

`InertiaPage` replays the request with the right headers:

```csharp
var page = await (await _client.InertiaGetAsync("/dashboard")).GetInertiaPageAsync();

new AssertableInertia(page).HasDeferred("sidebar", "stats").Missing("stats");

var loaded = await page.LoadDeferredPropsAsync(_client, "sidebar");     // all groups when none are named
new AssertableInertia(loaded).Has("stats");

new AssertableInertia(page).HasScroll("posts");
var next = await page.LoadNextPageAsync(_client, "posts");
var previous = await next.LoadPreviousPageAsync(_client, "posts");

var only = await page.ReloadOnlyAsync(_client, "users");
var except = await page.ReloadExceptAsync(_client, "users");
```

`HasScroll(path)` asserts scroll metadata. `HasScroll(path, currentPage, nextPage)` also checks the page values. The next-page and previous-page helpers use the metadata and send the appropriate append or prepend intent.

`ReloadOnlyAsync` asserts that `"users"` is in the result. `ReloadExceptAsync` asserts that `"users"` is missing.

## InertiaPage members

`Props`, `Raw`, `Prop(path)`, `HasProp(path)`, `PropBigInteger(path)`, `DeferredProps`, `MergeProps`, `PrependProps`, `DeepMergeProps`, `MatchPropsOn`, `RescuedProps`, `SharedProps`, `ScrollProps`, `OnceProps`, `LiveProps`, `Flash`, `EncryptHistory`, `ClearHistory`, `PreserveFragment`, `PreserveBigIntegers`.

<Callout type="tip" title="Cookies and redirects">
Flash and errors travel in a cookie across the redirect, so use a client that keeps cookies. Disable `AllowAutoRedirect` to assert the redirect itself. Then follow the redirect with a second `InertiaGetAsync` to read the flash or errors.
</Callout>

## Testing a form with antiforgery

Keep cookies and disable redirects on the test client. Then:

1. Load the form.
2. Send the form's XSRF token on the Inertia POST.
3. Follow the redirect.

```csharp
using var formPage = await _client.InertiaGetAsync("/users/create");
using var request = new HttpRequestMessage(HttpMethod.Post, "/users")
{
    Content = JsonContent.Create(new { email = "" }),
};
request.Headers.Add("X-Inertia", "true");
request.Headers.Add("X-Requested-With", "XMLHttpRequest");
request.Headers.Referrer = new Uri(_client.BaseAddress!, "/users/create");
request.WithXsrfToken(formPage);
using var response = await _client.SendAsync(request);
Assert.Equal(HttpStatusCode.Redirect, response.StatusCode);
using var redirected = await _client.InertiaGetAsync("/users/create");
await redirected.AssertInertiaAsync(page => page.HasErrors().HasError("email"));
```

Import `System.Net` and `System.Net.Http.Json`. For a named error bag, use `HasErrorBag("createUser")` and `HasError("email", bag: "createUser")`. Dotted keys such as `items.0.email` are matched as flat error keys. With all errors enabled, a message assertion matches any message. `GetXsrfToken()` and `WithXsrfToken()` accept custom cookie and header names. The cookie container must keep the antiforgery cookie as well as the Inertia state cookie.
