Use this guide to add Inertia to an existing ASP.NET Core app. To create a new app with the server and frontend already connected, follow [First 10 minutes](/docs/first-10-minutes).

Run these commands from the folder of your existing server project. Every app needs the core package:

```sh
dotnet add package Inertia.Net --version 1.9.8
```

For MVC, also install `Inertia.Net.Mvc`. For FastEndpoints, install `Inertia.Net.FastEndpoints`.
Use version `1.9.8` for each. You also need Node.js and Vite to build the client. See
[installation](/docs/installation) for all packages, or [client setup](/docs/client-setup) for the frontend files.

The **root template** is your HTML shell. A **page component** is the React, Vue or Svelte file that renders a screen.
**Props** are the named values your C# handler passes to that component.

Every app needs the same four things:

## 1. Register the services

Choose one backend style. All three use the same protocol middleware and the same `Render(...)` result.

<Tabs>
  <Tab label="Minimal API">

```csharp
// Program.cs
var builder = WebApplication.CreateBuilder(args);

builder.Services.AddValidation();                    // .NET 10 source-generated validation
builder.Services.AddAntiforgery(o => o.HeaderName = InertiaHeaders.XsrfToken);
builder.Services.AddInertia(o =>
{
    o.Share("appName", "Demo");
    o.Pages.Directory = "ClientApp/pages";
});

var app = builder.Build();

app.UseStaticFiles();                                // serves wwwroot/build (Vite output)
app.UseInertia();                                    // before the endpoints
app.UseInertiaAntiforgery();                         // XSRF-TOKEN cookie; 419 for unsafe requests without it

app.MapGet("/", () => Render("Home", new InertiaProps
{
    ["greeting"] = "Hello from .NET",
}));

app.Run();
```

  </Tab>
  <Tab label="MVC">

```csharp
// Program.cs
var builder = WebApplication.CreateBuilder(args);

builder.Services.AddInertia();
builder.Services.AddControllersWithViews().AddInertiaMvc();   // add .UseRazorRootView() here if you want Razor
builder.Services.AddAntiforgery(o => o.HeaderName = InertiaHeaders.XsrfToken);

var app = builder.Build();

app.UseStaticFiles();
app.UseInertia();
app.UseInertiaAntiforgery();
app.MapControllers();
app.Run();
```

```csharp
using Microsoft.AspNetCore.Mvc;

public sealed class HomeController : Controller
{
    [HttpGet("/")]
    public IResult Index() => Render("Home", new InertiaProps
    {
        ["greeting"] = "Hello from .NET",
    });
}
```

  </Tab>
  <Tab label="FastEndpoints">

```csharp
// Program.cs
using FastEndpoints;
using Inertia.Net.FastEndpoints;

var builder = WebApplication.CreateBuilder(args);

builder.Services.AddInertia();
builder.Services.AddFastEndpoints();
builder.Services.AddAntiforgery(o => o.HeaderName = InertiaHeaders.XsrfToken);

var app = builder.Build();

app.UseStaticFiles();
app.UseInertia();
app.UseInertiaAntiforgery();
app.UseFastEndpoints(c => c.ConfigureInertia());           // validation redirect + Precognition
app.Run();
```

```csharp
using FastEndpoints;
using Inertia.Net.FastEndpoints;

public sealed class HomeEndpoint : EndpointWithoutRequest<InertiaResult>
{
    public override void Configure() => Get("/");

    public override Task<InertiaResult> ExecuteAsync(CancellationToken ct) =>
        Task.FromResult(Render("Home", new InertiaProps { ["greeting"] = "Hello from .NET" }));
}
```

  </Tab>
</Tabs>

<Callout type="tip" title="Why AddValidation and antiforgery up front?">
`AddValidation()` enables the Minimal API integration used by `.WithInertiaValidation()`. `UseInertiaAntiforgery()` issues the `XSRF-TOKEN` cookie and validates every unsafe request. This means forms work from the start.
</Callout>

See [Precognition](/docs/precognition) for live form validation.

## 2. Add the root template

The root template is an HTML file in the content root. The default name is `app.html`.

```html
<!-- app.html -->
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>My app</title>
  @inertiaHead
  @viteReactRefresh
  @vite("ClientApp/app.tsx")
</head>
<body>
  @inertia
</body>
</html>
```

For Vue and Svelte, remove `@viteReactRefresh` and point `@vite` at `ClientApp/app.ts`. The `@inertia` token is required. [Pages and responses](/docs/pages-and-responses#the-root-template) describes the other tokens.

Make sure the build copies `app.html` to the output directory and the publish directory:

```xml
<ItemGroup>
  <Content Include="app.html" CopyToOutputDirectory="PreserveNewest" CopyToPublishDirectory="PreserveNewest" />
</ItemGroup>
```

## 3. Create the page component

The page name you pass to `Render` must match the client resolver, which finds the page component for a name. With `@inertiajs/vite`, the resolver maps `ClientApp/pages/**` automatically.

<Tabs>
  <Tab label="React">

```tsx
// ClientApp/pages/Home.tsx
export default function Home({ greeting }: { greeting: string }) {
  return <h1>{greeting}</h1>
}
```

  </Tab>
  <Tab label="Vue">

```vue
<!-- ClientApp/pages/Home.vue -->
<script setup lang="ts">
defineProps<{ greeting: string }>()
</script>

<template>
  <h1>{{ greeting }}</h1>
</template>
```

  </Tab>
  <Tab label="Svelte">

```svelte
<!-- ClientApp/pages/Home.svelte -->
<script lang="ts">
  let { greeting }: { greeting: string } = $props()
</script>

<h1>{greeting}</h1>
```

  </Tab>
</Tabs>

The client entry only needs to start Inertia:

<Tabs>
  <Tab label="React">

```tsx
// ClientApp/app.tsx
import { createInertiaApp } from '@inertiajs/react'

createInertiaApp()
```

  </Tab>
  <Tab label="Vue">

```ts
// ClientApp/app.ts
import { createInertiaApp } from '@inertiajs/vue3'

createInertiaApp()
```

  </Tab>
  <Tab label="Svelte">

```ts
// ClientApp/app.ts
import { createInertiaApp } from '@inertiajs/svelte'

createInertiaApp()
```

  </Tab>
</Tabs>

<Callout type="info" title="Not using @inertiajs/vite?">
Pass your own `resolve` and `setup` functions to `createInertiaApp`. The [client setup](/docs/client-setup) page shows both forms for React, Vue and Svelte.
</Callout>

## 4. Run it

If your app has no Vite setup yet, follow the package and configuration steps in [Client setup](/docs/client-setup#install-the-client). Use `ClientApp/app.tsx` (React) or `ClientApp/app.ts` (Vue and Svelte) as the Vite entry to match the root template above.

For the `createInertiaApp()` examples above, add `@inertiajs/vite@^3` as a development dependency. In `vite.config.ts`, import `inertia` from `@inertiajs/vite` and add `inertia()` after your framework plugin in the `plugins` array. The `inertia()` plugin resolves the page files under `ClientApp/pages`.

From the project directory, install dependencies and start Vite with your package manager:

| Package manager | Install dependencies | Start Vite | Build assets |
|---|---|---|---|
| npm | `npm install` | `npm run dev` | `npm run build` |
| Bun | `bun install` | `bun run dev` | `bun run build` |
| pnpm | `pnpm install` | `pnpm run dev` | `pnpm run build` |
| Yarn | `yarn install` | `yarn run dev` | `yarn run build` |

Keep Vite running in terminal 1. Start ASP.NET Core in terminal 2:

```sh
dotnet watch     # Development environment
```

Open the URL that `dotnet watch` prints, not the Vite URL. The first visit to `/` should display “Hello from .NET”.

For production, run the build command from your row of the table, then publish the app:

```sh
dotnet publish -c Release
```

Deploy `wwwroot/build` and `app.html` with the published app.
